### <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f680/512.gif" width="25"> Flagship Engineering Feats

#### 🛡️ **Privacy-First Clinical Intelligence Platform**
> *Re-imagining Mental Health Support through Decentralized AI*
> - **Architecture**: Deployed quantized **LLaMA 3.2** locally via **Ollama**, ensuring 0% data leakage to external APIs.
> - **Innovation**: Built a hybrid **Semantic + Keyword Retrieval** system using **ChromaDB**, achieving high-fidelity clinical grounding.
> - **Safety**: Integrated a multi-layered guardrail system featuring regex-based crisis detection and PHQ-9/GAD-7 automated screening.

#### 🤖 **Agentic Multimodal Scheduler (Autonomous Agent)**
> *The Future of Hyper-Personalized Productivity*
> - **Intelligence**: Utilized **Google Gemini** for multimodal extraction, transforming unstructured Gmail data and PDF syllabi into structured JSON metadata.
> - **Reasoning**: Developed a custom **Importance Scoring Mechanism** and a sentiment-aware engine to prioritize calendar events dynamically.
> - **Security**: Implemented full **OAuth2** flows and background task workers for large-scale, asynchronous email synchronization.

#### 📊 **Predictive Analytics Decision Support (UIDAI Data)**
> - **Analysis**: Built a robust **Logistic Regression** engine to identify demographic enrollment gaps.
> - **Visualization**: Created interactive, geospatial dashboards for real-time risk-scoring and trend prediction.
