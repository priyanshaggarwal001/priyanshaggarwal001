#### 🛡️ **Privacy-First Clinical Intelligence Platform**
> *Re-imagining Mental Health Support through Decentralized AI*
> - **Architecture**: Deployed quantized **LLaMA 3.2** locally via **Ollama**, ensuring 0% data leakage.
> - **Innovation**: Built a hybrid **Semantic + Keyword Retrieval** system using **ChromaDB**.
> - **Safety**: Integrated a multi-layered guardrail system featuring regex-based crisis detection.

#### 🤖 **Agentic Multimodal Scheduler (Autonomous Agent)**
> *Hyper-Personalized Productivity with Multimodal Reasoning*
> - **Intelligence**: Utilized **Google Gemini** for multimodal extraction from Gmail content and PDFs.
> - **Reasoning**: Developed a custom **Importance Scoring Mechanism** to prioritize calendar events.
> - **Security**: Implemented full **OAuth2** flows and background task workers for email sync.

#### 📊 **Predictive Analytics Decision Support (UIDAI Data)**
> - **Analysis**: Built a robust **Logistic Regression** engine to identify demographic enrollment gaps.
> - **Visualization**: Created interactive, geospatial dashboards for real-time risk-scoring.
